v1.03 – Navigation Stabilization & Reading Experience Improvement

本版本主要聚焦于应用整体结构的稳定性，以及阅读与设置模块的使用体验优化。
This release focuses on stabilizing the overall application structure and improving the user experience of the reading and settings features.

主要更新内容 / Key Updates：

使用 RegisterRoute 稳定 Shell 导航结构
Stabilized Shell-based navigation using RegisterRoute

明确区分主 Tab 页面（Bookshelf / Search / Settings）与子页面
Clearly separated main TabBar pages (Bookshelf / Search / Settings) from sub-pages

优化 Reading 页面布局，提供更沉浸式的阅读体验
Improved the Reading page layout to provide a more immersive reading experience

改进 Settings 相关页面（Appearance、Help & Support 等）
Refined Settings-related pages, including Appearance and Help & Support

修复 v1.02 中出现的多项 XAML 绑定、导航与布局问题
Fixed multiple XAML binding, navigation, and layout issues found in v1.02

该版本为后续功能扩展建立了稳定基础，并符合 INFT2051 课程项目对迭代式开发的要求。
This version establishes a stable baseline for future feature development and aligns with the iterative development approach required for the INFT2051 course project.
